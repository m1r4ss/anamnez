# Анамнез

Спецпроект о профилактике: «Жалоб нет» — ещё не диагноз.

- `yarn` или `npm i` — установить зависимости
- `npm start` — локальная разработка (`dev_build`)
- `npm run build` — сборка в `docs` для GitHub Pages

Яндекс Метрика: номер счётчика в `src/partials/analytics.html` (`window.YM_ID`).
Цели: story_view, shadow_view, card_view, card_done, complaints, gosuslugi, mark_done, therapist, share_parent, template, page_end, cta_*.
